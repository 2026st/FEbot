# /fe-quiz スラッシュコマンドの追加

## 概要

Slack の `/fe-quiz` スラッシュコマンドを追加し、基本情報技術者試験の過去問・練習問題をカテゴリや分野で絞り込んで出題できるようにした。

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `src/febot/quiz.py` | `QuizItem` に `category` / `field` フィールド追加。IPA 科目A 過去問パーサー追加。`pick_filtered()` 追加。 |
| `src/febot/slack_app.py` | `/fe-quiz` スラッシュコマンドハンドラー追加。`/fe-help` の説明を更新。 |
| `README.md` | `/fe-quiz` の使い方を「実行時の挙動」セクションに追記。Slash Commands 一覧に追加。 |

## コマンド仕様

```
/fe-quiz              → 全問ランダム出題
/fe-quiz 科目A  (a)   → 科目A（知識問題）のみ
/fe-quiz 科目B  (b)   → 科目B（アルゴリズム）のみ
/fe-quiz <分野名>     → 分野で絞り込み
```

分野キーワード例: `OS`、`ネットワーク`、`データベース`、`セキュリティ`、`アルゴリズム`、`表計算`

## 問題ソース

- `data/corpus/sample-questions.md` — オリジナル練習問題（構造化済み）
- `data/corpus/ipa-fe-2023r05-cbt-kamoku-a-qs.md` + `-ans.md` — IPA 令和5年度 科目A 公開問題 20問

## 注意

- IPA 科目A 問題は PDF からのテキスト抽出のため、図表を含む問題は選択肢のみ正確に表示される。
- 旧形式（2016〜2018年）の問題ファイルはテキスト抽出が空のため読み込みをスキップしている。
- 科目B IPA 過去問は選択肢が「ア〜ク」など多肢になるため現時点では未対応。
