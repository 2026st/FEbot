# スレッド内会話履歴の保持（2026-05-19）

## 背景

- RAG は毎回単発の質問のみ LLM に渡しており、スレッド内の文脈を利用できなかった。
- 練習問題の `pending_quiz` がボット投稿の `ts` をキーにしていた一方、ユーザ返信の `thread_ts` はスレッド親のため、**チャンネルでは採点が動かない**状態だった。

## 変更内容

| 項目 | 内容 |
|------|------|
| `thread_session.py` | スレッドキー `channel:thread_root_ts` で履歴・出題中クイズを管理 |
| `slack_app.py` | 採点キーをスレッド親に統一。`bot_active` スレッドの `message.channels` で追質問を RAG にルーティング |
| `rag.py` / `web_search.py` | プロンプト先頭に `【これまでの会話】` を付与（埋め込み検索は直近発話のみ） |

## 制限

- 履歴は **プロセス稼働中のインメモリのみ**（再起動で消える）。
- ボット起動前の Slack メッセージはバックフィルしない。
- 既定で直近 **10 ターン**（`THREAD_HISTORY_MAX_TURNS`）、最大 **500 スレッド**（`THREAD_MAX_SESSIONS`）。

## 動作例

1. チャンネルで `@FEbot 過去問` → スレッドで `イ` → 正誤・解説。
2. 同スレッドで「なぜウが違うの？」（メンション不要）→ 直前の会話を踏まえた回答。
