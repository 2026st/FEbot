# Q: 公開鍵暗号方式について教えてください

# 【公開鍵暗号方式とは？】

公開鍵暗号方式は、*2種類の鍵*を使って情報を安全にやり取りする暗号の仕組みです。
基本情報技術者試験でも頻出のテーマなので、しっかり理解しておきましょう！


## 【2種類の鍵】

公開鍵暗号方式では、以下の2つの鍵をペアで使います。

- *公開鍵（Public Key）*：誰にでも公開してよい鍵
- *秘密鍵（Private Key）*：自分だけが持つ、絶対に公開しない鍵

この2つは *必ずペア* になっており、片方で暗号化したものは、もう片方でしか復号できません。


## 【仕組みのイメージ】

```
【送信者 → 受信者へ秘密のメッセージを送る場合】

1. 受信者が「公開鍵」を送信者に渡す（誰に見られてもOK）
2. 送信者は「公開鍵」でメッセージを暗号化して送る
3. 受信者は自分だけが持つ「秘密鍵」で復号する

公開鍵で暗号化 → 秘密鍵でのみ復号できる！
```

たとえるなら…
- 公開鍵 ＝ *誰でも使える南京錠*（かけることはできるが開けられない）
- 秘密鍵 ＝ *その南京錠を開ける唯一の鍵*（自分だけが持つ）


## 【共通鍵暗号方式との違い】

```
方式           鍵の数     特徴
-----------------------------------------
共通鍵暗号方式  1種類      速いが、鍵の受け渡しが危険
公開鍵暗号方式  2種類      安全だが、処理が遅い
```

- *共通鍵暗号方式*：送信者と受信者が *同じ鍵* を使う → 鍵を相手に渡す際に盗まれるリスクがある
- *公開鍵暗号方式*：公開鍵は誰に見られても問題ない → 鍵の受け渡しが安全


## 【試験でよく問われるポイント】

- 暗号化に使う鍵：*受信者の公開鍵*
- 復号に使う鍵：*受信者の秘密鍵*
- 公開鍵は *誰に配っても安全*
- 秘密鍵は *絶対に公開しない*
- 処理速度は共通鍵より *遅い*（そのためSSLなどでは両方を組み合わせて使う）


## 【デジタル署名への応用】

公開鍵暗号方式は「なりすまし防止」にも使われます。

```
【送信者が署名する場合】

1. 送信者が「秘密鍵」で署名を作成
2. 受信者が「送信者の公開鍵」で署名を検証

→ 秘密鍵は本人しか持っていないので、本人確認ができる！
```


## 【まとめ】

- 公開鍵（誰でも使える）で *暗号化*
- 秘密鍵（自分だけ）で *復号*
- 鍵の配送問題を解決した安全な方式
- 処理速度は遅めなので、実際はハイブリッドで使われることが多い

試験では「どの鍵で暗号化・復号するか」を正確に覚えておくことが大切です！ 💡
